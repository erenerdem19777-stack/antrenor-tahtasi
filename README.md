# Antrenör Tahtası · by SERKAN İNAL

Futbol antrenörleri için dokunmatik taktik tahtası ve animasyonlu antrenman kütüphanesi (web / iPhone sürümü).

Uygulama antrenör şifresiyle korunur. Kayıtlar her cihazın kendi içinde tutulur; bu depoda kişisel veri yoktur.

**iPhone'a kurulum:** Safari ile sayfayı açın → Paylaş → Ana Ekrana Ekle.
